# bftport

Консольный менеджер `kubectl port-forward` с мышью: запускайте и останавливайте проброс сервисов вживую, добавляйте новые, собирайте наборы (шаблоны) и запускайте их одним нажатием.

## Требования

- [Node.js](https://nodejs.org) 18 или новее
- `kubectl` в `PATH`
- Windows Terminal (на Windows) или любой терминал с поддержкой мыши

## Установка

```
npm install -g git+https://<gitlab-хост>/<группа>/bftport.git
```

Если репозиторий приватный, нужен доступ по SSH или токену, как для обычного `git clone`:

```
npm install -g git+ssh://git@<gitlab-хост>/<группа>/bftport.git
```

Обновление: `bftport --update` сравнит установленную версию с репозиторием и обновится, если есть новее (или сообщит, что версия актуальна). Нужен `git` с доступом к репозиторию. Удаление: `npm uninstall -g bftport`.

Проверка: `bftport --version`, `bftport --help` (покажет, куда установлено и где лежит база).

## Первый запуск

1. Выполните `bftport`.
2. Нажмите `K` и укажите путь к вашему kubeconfig (общий для всех сервисов).
3. Стартовый набор сервисов уже в списке. Свои добавляйте клавишей `A`; кнопка «Выбрать из кластера» (`F2`) подтянет namespace, service и порты прямо из кластера.

## Где что лежит

| | Путь |
|---|---|
| Программа | `%APPDATA%\npm\node_modules\bftport` (Windows), `$(npm root -g)/bftport` (macOS/Linux) |
| Команда `bftport` | `%APPDATA%\npm\bftport.cmd`, она в `PATH` вместе с `npm` |
| Ваши данные | `~/.bftport/services.json` (сервисы, шаблоны, kubeconfig) |

Обновление программы базу не трогает. Чтобы сбросить всё к стартовому набору, удалите `~/.bftport/services.json`.

## Управление

| Клавиша | Действие |
|---|---|
| `↑` `↓`, колесо, клик | выбрать |
| `Enter`, `Пробел`, двойной клик | старт / стоп |
| `A` / `E` / `D` | добавить / изменить / удалить |
| `S` / `X` | запустить / остановить все видимые |
| `/`, `Ctrl+F` | поиск по имени, namespace, service, портам, статусу |
| `1` `2` `3`, `Tab` | вкладки: Все, Запущенные, Шаблоны |
| `G` | сохранить запущенные сервисы как шаблон |
| `K` | kubeconfig |
| `Q` | выход (пробросы останавливаются) |

Горячие клавиши работают и в русской раскладке.

### Шаблоны

Шаблон — именованный набор сервисов (например `or-bpmn`). На вкладке «Шаблоны» `Enter` или двойной клик запускает весь набор, повторное нажатие останавливает его. Проще всего: запустите нужные сервисы, нажмите `G` и назовите шаблон.

## Если не работает мышь

Выполните `bftport --keys`, кликните в окне и пришлите вывод. Если при клике ничего не печатается, мышь не доходит до программы. Попробуйте Windows Terminal.
