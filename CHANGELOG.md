# История версий

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [2.0.1] — 2026-10-30

### Добавлено
- Настройка открытия логов в отдельном окне на Windows и Debian.

## [2.0.0] — 2026-10-30

Новый интерфейс. Весь функционал версии 1.4.4 сохранён: те же вкладки, клавиши, форматы логов, поиск, экспорт, шаблоны, настройки, мышь и защита «только чтение».

### Добавлено
- Боковая панель деталей справа: у сервиса — адрес, цель, kubeconfig, автозапуск, шаблоны и кнопки действий; у пода — состояние, избранное, узел, IP, перезапуски, контейнеры и порты. Панель появляется от 108 колонок (на вкладке «Кластер» — от 140; иначе подробности остаются под списком).
- Группировка сервисов по namespace на вкладках «Избранное» и «Запущенные».
- Время работы проброса рядом со статусом.
- Палитра команд `Ctrl+P`: поиск по действиям текущей вкладки (дополняет клавиши).
- Два набора значков: Unicode (по умолчанию на Windows) и Nerd Font (по умолчанию на Linux/macOS), а также ASCII. Выбирается в настройках (`O` → «Значки») или переменной `BFTPORT_ICONS`.
- Переключатель вида логов в строке состояния просмотра («Как есть / logback / logback + JSON»), доступен кликом; клавиша `F` по-прежнему переключает по кругу.
- Строка состояния внизу: kubeconfig, число сервисов и работающих, сводка по подам, сообщения.
- Счётчики состояний в шапке (в работе, запуск, ошибка, стоп); фильтр namespace и отметка «только просмотр» на вкладке «Кластер».
- Откат: версия 1.4.4 зафиксирована тегом `v1.4.4` и веткой `legacy-1.x` (`npm install -g git+https://github.com/Norwi4/bftport.git#v1.4.4`).

### Изменено
- Новая цветовая тема (24-битный цвет), шапка вместо синей полосы с названием «BFTPort», вкладки в виде таблеток, полоса подсказок клавиш внизу.
- Окна форм, выбора, подтверждения и настроек оформлены в том же стиле.
- Сервисы в списках отсортированы по namespace (внутри группы порядок как в базе).
- Версии 1.x выше 1.4.4 выпускаться не будут.

## [1.4.4] — 2026-10-30

### Изменено
- В заголовке приложения вместо «Port Forwards» теперь «BFTPort».

## [1.4.3] — 2026-10-30

### Изменено
- Вкладка «Кластер»: колонка «ВОЗРАСТ» стала шире, заголовок больше не обрезается («ВОЗРА…»).
- Документация: README переписан как техническое руководство (возможности, архитектура, безопасность, справочники), добавлен этот файл.

## [1.4.2] — 2026-10-29

### Добавлено
- У каждой вкладки свой поиск: запрос и открытая строка поиска сохраняются при переключении вкладок и возвращаются.

### Исправлено
- Смена вида логов (`F`) больше не сбрасывает окно в конец: запоминается запись вверху окна и строка внутри неё.

## [1.4.1] — 2026-10-29

### Добавлено
- Третий вид логов «logback + JSON»: объекты и массивы JSON внутри сообщения раскладываются с отступами (числа, порядок ключей и содержимое строк не меняются).
- Переключение видов логов по кругу клавишей `F`: как есть → logback → logback + JSON. Экспорт «все логи» учитывает выбранный вид.

## [1.4.0] — 2026-10-29

### Добавлено
- Выделение текста мышью в просмотре логов (перетаскивание, двойной клик — слово, тройной — строка), копирование `Ctrl+C` / `Ctrl+Insert` в буфер ОС и через OSC 52; выделение привязано к тексту.

## [1.3.1] — 2026-10-29

### Исправлено
- Окно подтверждения (например, выхода) рисуется поверх любой вкладки. Раньше на вкладке «Кластер» оно не отображалось, и приложение казалось зависшим.

## [1.3.0] — 2026-10-29

### Добавлено
- Регулярные выражения в поиске по логам (`Ctrl+R`, переключатель `.*`).
- Экспорт логов пода в файл: «видимые» (то, что на экране) и «все логи пода» (потоком).
- Linux: проброс портов ниже 1024 через `sudo` с запросом пароля в приложении.

## [1.2.1] — 2026-10-29 (отозвана)

Содержала сброс путей kubeconfig из другой ОС при загрузке базы и примеры путей под текущую ОС; откатом `1.2.0` изменения отменены (коммит «Откат до версии 1.2.0»).

## [1.2.0] — 2026-10-29

### Добавлено
- Окно настроек (`O`): папка с kubeconfig, язык, сведения о приложении.
- Английский интерфейс и справка; перевод на лету, язык по умолчанию определяется по системе.

## [1.1.4] — 2026-10-29

### Добавлено
- Поиск в логах в стиле IntelliJ: подсветка всех совпадений, текущее ярче, счётчик, переходы, прокрутка с «зоной покоя».

## [1.1.3] — 2026-10-29

### Добавлено
- Прямые пробросы к подам видны на вкладке «Запущенные».
- `Enter` на вкладке «Кластер» управляет избранным сервисом пода (его порт, общее состояние на всех вкладках); `P` — проброс именно к этому поду.

## [1.1.2] — 2026-10-29

### Добавлено
- Вкладка «Все» переименована в «Избранное».
- Перенос пода в избранное (`F`): автоматический подбор Service и заполнение формы.

## [1.1.1] — 2026-10-29

### Исправлено
- Вкладка «Кластер» на больших кластерах: список подов запрашивается серверной таблицей вместо полного JSON (ошибка `maxBuffer exceeded`).

## [1.1.0] — 2026-10-29

### Добавлено
- Вкладка «Кластер»: все поды кластера без ручного добавления, проброс порта пода, логи. Режим «только просмотр» с защитой на уровне кода.

## [1.0.9] — 2026-10-29

### Добавлено
- Выбор пода и контейнера в логах, имя и время старта пода в верхней полосе.
- Вывод логов по шаблону logback (`~/.m2/logback-local.xml`).
- Редактирование текста с курсором во всех полях ввода и вставка из буфера обмена.

## [1.0.8] — 2026-10-29

### Добавлено
- Просмотр логов пода на весь экран (`L`): живой поток, прокрутка, фильтр, перенос строк.

## [1.0.0–1.0.7] — 2026-10-29

### Добавлено
- Интерактивный менеджер пробросов: запуск и остановка вживую, добавление сервисов, шаблоны, поиск, мышь (1.0.0).
- Подробная справка `bftport --help` (1.0.1), команда обновления `bftport --update` (1.0.2), версия в заголовке (1.0.3).
- Папка с kubeconfig и быстрое переключение конфигов (1.0.5), `bftport --version` в формате `bftport vX.Y.Z` (1.0.6), цветные статусы (1.0.7).
